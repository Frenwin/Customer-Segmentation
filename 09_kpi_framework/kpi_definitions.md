# KPI Definitions

Every KPI is computed from the analytical layer and implemented as a DAX measure of the same name in `11_powerbi` (see `11_powerbi/dax_measures/measures.dax`). Generated by `custseg.kpi`.

**Target policy (PRD 8.6):** a target is set only when the data provides a defensible benchmark (best observed period/cohort). Otherwise the KPI is *baseline only* until a controlled campaign (A/B test with hold-out) establishes an achievable uplift.

## Acquisition KPIs

### Total Customers

| Attribute | Value |
|---|---|
| Business definition | Distinct customers (customer_unique_id) with >= 1 delivered order in the window |
| Formula | `DISTINCTCOUNT(customer_key) over revenue orders` |
| DAX measure | `[Total Customers]` |
| Data source | mart.customer_rfm / pbi.fact_orders |
| Granularity | Customer; any period |
| Update frequency | Daily |
| Baseline | 93,104 |
| Target | - — Baseline only (volume KPI) |
| Business owner | Management |

### Registered Customers

| Attribute | Value |
|---|---|
| Business definition | All persons who ever placed an order (any status) - Olist has no sign-up table |
| Formula | `COUNTROWS(dim_customer)` |
| DAX measure | `[Registered Customers]` |
| Data source | dw.dim_customer |
| Granularity | Customer |
| Update frequency | Daily |
| Baseline | 96,096 |
| Target | - — Baseline only |
| Business owner | Management |

### New Customers

| Attribute | Value |
|---|---|
| Business definition | Customers whose first delivered order falls in the period |
| Formula | `COUNT customers WHERE first revenue order in period` |
| DAX measure | `[New Customers]` |
| Data source | mart.customer_kpi_monthly |
| Granularity | Month |
| Update frequency | Monthly |
| Baseline | 5,991 |
| Target | 7,061 — best observed month (2017-11, Black Friday) |
| Business owner | Marketing |

### Customer Acquisition Rate

| Attribute | Value |
|---|---|
| Business definition | New customers / customers acquired before the period start |
| Formula | `New Customers(t) / Cumulative Customers(t-1)` |
| DAX measure | `[Customer Acquisition Rate]` |
| Data source | mart.customer_kpi_monthly |
| Granularity | Month |
| Update frequency | Monthly |
| Baseline | 7.41% |
| Target | - — Baseline only - structurally declines as the base grows |
| Business owner | Marketing |

### Customer Growth Rate

| Attribute | Value |
|---|---|
| Business definition | Month-over-month growth of purchasing (active) customers |
| Formula | `(Purchasing(t) - Purchasing(t-1)) / Purchasing(t-1)` |
| DAX measure | `[Customer Growth Rate]` |
| Data source | mart.customer_kpi_monthly |
| Granularity | Month |
| Update frequency | Monthly |
| Baseline | -0.09% |
| Target | 0.00% — guardrail: >= 0% (no decline); last 6 months averaged ~0% |
| Business owner | Management |

## Retention KPIs

### Repeat Purchase Rate

| Attribute | Value |
|---|---|
| Business definition | Customers with 2+ delivered orders / purchasing customers |
| Formula | `COUNT(frequency >= 2) / COUNT(customers)` |
| DAX measure | `[Repeat Purchase Rate]` |
| Data source | dw.dim_customer (pbi) |
| Granularity | Customer |
| Update frequency | Monthly |
| Baseline | 3.00% |
| Target | - — Baseline only - lifetime rate depends on customer age; steer with the 6-month rate |
| Business owner | CRM |

### 6-Month Repeat Rate

| Attribute | Value |
|---|---|
| Business definition | Customers who make a second purchase within 182 days of the first (cohorts with >= 6 months of observation) - age-neutral, comparable across cohorts |
| Formula | `COUNT(2nd order <= 182 d after 1st) / cohort customers` |
| DAX measure | `[-]` |
| Data source | 08_customer_analytics/retention_analysis |
| Granularity | Acquisition quarter |
| Update frequency | Quarterly |
| Baseline | 3.13% |
| Target | 3.56% — best acquisition quarter (2017Q3) |
| Business owner | CRM |

### Retention Rate (3-month)

| Attribute | Value |
|---|---|
| Business definition | Customers who purchased in period P-1 and again in P / customers who purchased in P-1 |
| Formula | `Retained / Eligible` |
| DAX measure | `[Retention Rate]` |
| Data source | pbi.period_retention |
| Granularity | 3-month period |
| Update frequency | Quarterly |
| Baseline | 0.92% |
| Target | 1.08% — best observed period (Sep–Nov 17) |
| Business owner | CRM |

### Churn Rate (3-month)

| Attribute | Value |
|---|---|
| Business definition | 1 - Retention Rate on the same eligible base |
| Formula | `(Eligible - Retained) / Eligible` |
| DAX measure | `[Churn Rate]` |
| Data source | pbi.period_retention |
| Granularity | 3-month period |
| Update frequency | Quarterly |
| Baseline | 99.08% |
| Target | 98.92% — mirror of the retention target |
| Business owner | CRM |

### Inactive (Churned) Customer Share

| Attribute | Value |

| Granularity | Customer snapshot |
| Update frequency | Monthly |
| Baseline | 37.42% |

| DAX measure | `[Active Customer Rate]` |
